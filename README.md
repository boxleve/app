# Box Leve

**Sua TV mais simples.**

Tela inicial leve para TV Box Android. Este repositório guarda só as versões publicadas;
é daqui que o Box Leve baixa as atualizações.

- Site e instruções: https://boxleve.github.io
- Instalar pela TV (app Downloader): `boxleve.github.io/baixar`
- APK mais recente: https://github.com/boxleve/app/releases/latest/download/boxleve.apk
